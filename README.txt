RATINGS / REMINDER:
The website shows a small optional feedback reminder after 30 days, but only when the same visitor returns to this website in the same browser. It is not a push notification, does not detect whether someone installed the game, and does not collect/store a public rating. A real notification or central ratings system needs a backend, consent, and additional privacy/legal work.
